# Early 2000s Blog Project

This project is a simple website designed to resemble the aesthetic of early 2000s web design. It features a blog about a fictional character, complete with an index page, an about page, a blog page, and individual blog posts.

## Project Structure

```
early2000s-blog
├── src
│   ├── index.html        # Main entry point of the website
│   ├── about.html        # Information about the fictional character
│   ├── blog.html         # Main blog page with links to posts
│   ├── styles
│   │   └── main.css      # Minimal CSS styling for the website
│   └── posts
│       └── first-post.html # Template for the first blog post
└── README.md             # Documentation for the project
```

## Setup Instructions

1. Clone the repository or download the project files.
2. Open the `src` directory.
3. Open `index.html` in a web browser to view the homepage.
4. Navigate to the other pages using the provided links.

## Adding Content

- To add more blog posts, create new HTML files in the `src/posts` directory following the structure of `first-post.html`.
- Update `blog.html` to include links to the new posts.
- Modify `about.html` to include additional information about the character as needed.

## Customization

Feel free to modify the CSS in `styles/main.css` to change the appearance of the website. You can adjust colors, fonts, and layout to better fit your vision of the character's blog.
